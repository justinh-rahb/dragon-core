Cooldown fan

Cool down to
40 °C

After a heat session the fan keeps running until the chamber and heater element drop below this. Raise it for a hot room where they can't reach the default 40 °C — otherwise the fan runs indefinitely.

Foldback cut (advanced)

Danger — experts only. Changing this will likely cause the element to trip the 105 °C thermal protection (a latched over-temp fault needing a manual clear) — especially if raised. Only adjust it if you know exactly what you're doing, and always in conjunction with the built-in diagnostics page (/diag in the web UI — no USB needed) so you can watch the real element temperature while you tune. The fixed 105 °C hardware cutoff still protects the hardware regardless. If unsure, leave it on auto.
Element cut temperature
99 °C

The soft over-temp foldback holds the heater element just below this by cutting power, so it can't ratchet into the fixed 105 °C cutoff. Board default is auto — lower it if your element runs hot/slow, raise it (up to 104) for more chamber temperature. The fixed 105 °C hardware cutoff is unaffected. Turn Auto off to set a manual value, or back on to use the board default.

Filtration (auto mode)

Filter at bed temperature
30 °C

In Auto mode, the blower runs on its own once the printer bed reaches this temperature — filtering/circulating chamber air before the heater engages at the (higher) auto bed threshold. Fan-only: it never adds heat. Turn Off to disable the band. For on-demand filtration in any mode, use the Filtration button on the dashboard (or the dragonbreath_filter fan in Fluidd).
